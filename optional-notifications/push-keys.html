Notification keys (one time, per school)

The keys are made inside this phone/computer only. Nothing is sent anywhere. Make them once per school and keep them. If you make new keys later, every parent has to press "Turn on notifications" again.

1) PUBLIC key (goes in config.js as VAPID_PUBLIC_KEY)

2) PRIVATE key (goes ONLY in Supabase function secrets as VAPID_PRIVATE_KEY)

Never upload the private key to GitHub and never send it to anyone.
